# ProofRAI

ProofRAI is an assurance workspace for language model assistants. It covers one target assistant, HireAssist, which helps recruiters summarize applications, answer candidate questions and draft screening notes.

## Repository layout

The repository is structured into backend, frontend, scripts, docs and examples directories.

## Development

Run checks:

    make check

Start backend service:

    make dev-backend

Start frontend service:

    make dev-frontend
